Calcul réseau — Méthode rapide

  1. Convertir le masque en CIDR
  2. Identifier l'octet "intéressant" (non 0 ni 255)
  3. Calculer le pas = 256 − valeur_octet
  4. Adresse réseau = multiple du pas inférieur à l'octet hôte
  5. Broadcast = adresse réseau suivante − 1
Ex: 192.168.10.33/27 → pas=32 → réseau=.32 → broadcast=.63

VLAN

  • VLAN = Virtual LAN, segmentation logique d'un switch
  • Trunk = port qui transporte plusieurs VLANs (étiquetage 802.1Q)
  • Access = port appartenant à un seul VLAN
  • Native VLAN = VLAN par défaut non étiqueté sur trunk (VLAN 1)
  • Inter-VLAN routing = routeur ou switch L3
  • 802.1Q = standard d'encapsulation VLAN (tag 4 octets)

Spanning Tree Protocol (STP)

  • But : éviter les boucles sur les réseaux commutés
  • Root bridge : switch élu (BID le plus bas)
  • États des ports : Blocking → Listening → Learning → Forwarding
  • RSTP (802.1w) = version rapide de STP

DHCP — Processus DORA

Discover → Offer → Request → Acknowledgement
  • Discover : client broadcast (cherche serveur DHCP)
  • Offer : serveur propose une IP
  • Request : client accepte l'offre
  • Ack : serveur confirme le bail

GPO — Group Policy

  • Les GPO s'appliquent dans l'ordre : L → S → D → OU (Local → Site → Domaine → OU)
  • La GPO la plus proche (OU) est la dernière appliquée = prioritaire
  • Bloc héritage : empêche l'héritage des GPO parentes
  • Enforced (No Override) : force l'application même si bloc héritage
  • Loopback processing : applique GPO de l'OU ordinateur à l'utilisateur
  • Commande de forçage : gpupdate /force
  • Résultat : gpresult /h rapport.html

⚠️ Pièges courants

  • DNS utilise TCP ET UDP sur le port 53 (UDP pour requêtes, TCP pour transferts de zone)
  • ARP fonctionne à la couche 2/3 (liaison/réseau)
  • Le broadcast d'un réseau N'EST PAS utilisable comme adresse hôte
  • DHCP client écoute sur 68, serveur sur 67
  • SSH = port 22 (pas 23 qui est Telnet)
  • HTTPS = port 443 (pas 80 qui est HTTP)
  • FTP a 2 ports : 20 (données) et 21 (commandes)
  • LDAP non sécurisé = 389, sécurisé (LDAPS) = 636
  • RDP = port 3389 (Windows Bureau à distance)
  • Un /30 n'a que 2 hôtes utilisables (point à point)
  • OSPF utilise la bande passante comme métrique (pas les sauts)
  • RIP est limité à 15 sauts maximum
  • La Distance Administrative la plus basse est la plus prioritaire
